# Rock Paper Scissors Game (React + Vite)

A modern, high-contrast, fully responsive **Rock, Paper, Scissors** arena game built with **React** and **Vite**.

## Features
- **Strict Color Tokens**: Dark violet `#12101F`, Card surface `#1C1930`, Borders `#332F52`, Text `#F4F2FF`, Player coral `#FF5C7A`, CPU cyan `#3DE0FF`, Highlight yellow `#FFD84D`.
- **Custom 3px Stroke SVG Icons**: Rock, Paper, Scissors, Tilted Shaking Fists, Star Outline, Trophy, Defeat Cross, and Draw Equal.
- **Natural Game Flow**: Home ➔ Countdown (shaking fists & audio) ➔ Battle (3D CPU card flip, outcome reason) ➔ Result (star spin, confetti, career streaks).
- **Fully Responsive**: Seamless fluid layout across Mobile phones (320px–480px), Tablets (768px–1024px), Laptops and Large 4K Desktops.
- **Desktop Keyboard Shortcuts**:
  - `1` / `R` = Rock
  - `2` / `P` = Paper
  - `3` / `S` = Scissors
  - `Space` / `Enter` = Next Round / Play Again
  - `Esc` = Close Dialogs
- **Detailed In-Game Guide**: Complete "How to Play" rulebook, match mode explanation, and career stats tracking.

## Running the Project

```bash
cd frontend
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
